# Changelog

## [0.1.0] - 2026-11-03

### Added
- Image to ASCII conversion (PNG, JPG, WebP, BMP, GIF, SVG).
- Video/GIF to ASCII conversion (MP4, MOV, WebM, AVI, GIF).
- Output formats: PNG, GIF, SVG, TXT, HTML, MP4, WebM.
- Standalone HTML/Canvas animation export.
- Grayscale, color and monochrome ASCII modes.
- Multiple character palettes (standard, dense, minimal, blocks, binary, custom).
- Contrast-aware logo rendering.
- Project management with SQLite.
- Background job queue with separate worker service.
- REST API with OpenAPI/Swagger documentation.
- Bearer token authentication.
- React + TypeScript + Tailwind CSS frontend.
- Systemd services with auto-restart.
- HestiaCP/Nginx deployment template.
- Comprehensive pytest test suite.
